# 2.2.2

Changed from 2.1.1:

- Added `map_letters` param to `normalize_text`: the hamza-fold mapping
  (`أ`/`إ`/`آ`/`ٱ`/`ٲ`/`ٳ` → `ا`) is now overridable, and defaults to the
  actual `MAP_LETTERS` dict (not `None`) so you can see exactly what's
  mapped right in the function signature.
  ```python
  # add a mapping on top of the default
  normalize_text(text, map_letters={**MAP_LETTERS, "ة": "ه"})
  # drop one
  normalize_text(text, map_letters={k: v for k, v in MAP_LETTERS.items() if k != "أ"})
  ```
- `MAP_LETTERS` promoted to a module-level constant (was a dict rebuilt
  inside `normalize_text` on every call).
- `أ`→`ا` and `إ`→`ا` folding restored to the default map (previously
  removed in 1.1.0 to match production training code; re-added at your
  request).
- `normalize_numbers` unchanged, no new params, this release only touches
  letter folding in `normalize_text`.

Full test suite (36 tests) and the 230,546-field, 115k-line real
benchmark corpus sweep both pass clean, zero crashes, zero regressions.
