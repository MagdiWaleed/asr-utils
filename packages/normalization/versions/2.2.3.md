# 2.2.3

Changed from 2.2.2:

- Fixed: `ٱ`/`ٲ`/`ٳ` (hamza-variant alifs, U+0671-0673) were being deleted
  by the Urdu/Persian-contamination strip before the `map_letters` fold
  step ever got a chance to run on them, so `MAP_LETTERS`' mapping for
  those three characters was dead code, silently dropping the letter
  instead of folding it (`ٱحد` → `حد`, not `احد`). Now protected through
  that strip the same way `enable_punc` characters already were.
  `ٱحد`/`ٲحد`/`ٳحد` now correctly normalize to `احد`.
- Added `packages/normalization/example.py` and `example.md`: runnable
  and documented usage examples, kept in sync, covering every parameter
  including add/remove cases for `map_letters`.

Full test suite (36 tests) and the 230,546-field, 115k-line real
benchmark corpus sweep both pass clean, zero regressions from the fix.
