# 2.0.0

Changed from 1.1.0:

- BREAKING: import path moved from `asr_normalization` to the shared `asr_utils` namespace.
  ```python
  # before
  from asr_normalization import normalize_text, normalize_numbers
  # now
  from asr_utils.normalization import normalize_text, normalize_numbers
  ```
- No behavior change to `normalize_text` / `normalize_numbers` themselves.
- Package is now a PEP 420 namespace package (no `asr_utils/__init__.py`), so installing other `asr-utils` categories alongside this one merges into the same `asr_utils` import root without conflict.
