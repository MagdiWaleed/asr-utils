# 1.0.0

Initial release.

- `normalize_text(text, enable_punc=None)`: lowercase, NFC normalize, strip Urdu/Persian/extended-Arabic contamination, fold hamza variants and ة to ا/ه, strip diacritics/tatweel, strip punctuation (keep only Arabic letters, a-z, 0-9), collapse whitespace.
- `normalize_numbers(text)`: Arabic-Indic digits to ASCII, Arabic/English number words to digit strings, collapse spaced digit runs ("2 0 2 4" to "2024").
- Known issue: Arabic-Indic digits get silently stripped before conversion when embedded in text run through `normalize_text` (`URDU_CHARS_PATTERN` overlaps the digit range and runs before `normalize_numbers`). Fixed in 1.1.0.
