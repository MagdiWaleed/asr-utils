# 1.1.0

Changed from 1.0.0:

- Fixed: `normalize_numbers` now runs before the Urdu/Persian-contamination strip, so Arabic-Indic digits no longer get silently dropped.
- Added `eot_token` param to `normalize_text`: protects an end-of-turn marker through normalization, re-glues it with exactly one space on both sides, strips a leading stray one.
- Added `enable_punc` support to `normalize_text`: keep a chosen punctuation set instead of stripping all of it, with spacing rules (no space before, one space after, except a digit.digit / digit,digit decimal separator) and leading-punctuation stripping.
- Added ellipsis collapsing: runs of 2+ periods (with or without whitespace between) collapse to a single ".".
- Added thousands-separator flattening in `normalize_numbers`: "100,000" to "100000".
- Narrowed Arabic character folding: dropped أ/إ to ا and ة to ه, kept only آ/ٱ/ٲ/ٳ to ا.
- Removed unused `ARABIC_NUM_PATTERN` and `CLEAN_PUNC_PATTERN` constants (dead code, not referenced by either function).

Import path unchanged: `from asr_normalization import normalize_text, normalize_numbers`.
