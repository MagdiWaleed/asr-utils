# 3.1.0

Changed from 3.0.0:

No signature or import-path change. Number-word output changes for many
inputs (all toward the correct value), so WER/CER scored with 3.0.0 is
not directly comparable to 3.1.0 scores.

Parser (`normalize_numbers`)
- Rewritten to build values scale by scale, so a compound before a
  multiplier is multiplied as a whole: `"خمسة وعشرين ألف"` -> `25000`
  (was `20005`), `"ثلاثمائة وخمسين ألف"` -> `350000` (was `50300`). The
  edge case documented as unresolved in 3.0.0 is fixed.
- A digit string before a multiplier joins the number: `"5 مليون"`,
  `"3.5 مليون"` -> `3500000`, `"11 ألف وتسعة وتسعين"` -> `11099`.
- `"ونص"`/`"وربع"` after a multiplier: `"مليون ونص"` -> `1500000`.
- Two adjacent bare ones are a range: `"تلات أربع"` -> `"3 4"` (was `34`).
  Three or more still join digit by digit.
- One-و-one is a list, not a sum: `"ثلاثة و اربعة"` -> `"3 و 4"` (was `7`).

Vocabulary
- Hamza spellings (`أربعة`, `أربعين`, `إثنين`), MSA nominative duals
  (`مئتان`, `ألفان`, `مليونان`), feminine teens (`اثنتا عشرة`,
  `ثماني عشرة`), plural `آلاف`.
- Egyptian (`تلاتة`, `اتنين`, `تمانية`, `ربعمية`, `تلات تلاف`) and
  Egyptian/Levantine fused teens (`اتناشر`, `خمستاشر`, `خمسطعش`, ...).
- Capitalized English (`One hundred`, `FIVE`).
- Extended Arabic-Indic digits (`۰-۹`) and Arabic decimal/thousands
  separators (`٫`, `٬`).

Context rules (each from a real transcript misfire), words stay words when:
- `أحد`/`إحدى` are not before a tens word (`لا أحد`, `إحدى المدارس`).
- Plural multipliers stand alone (`آلاف الأشخاص`, `ملايين الناس`).
- Egyptian `مية` has no unit, amount word, or `في المية` next to it (water).
- `ست البيت`, ordinals (`السادس عشر`), idioms (`الف عافية`, `شكرا مليون`),
  pronoun "one" (`كل واحد`, `واحدة من`, `one of`), `تمن` (price) not before
  a multiplier.

Fixed: text deleted, merged, or truncated
- Tanwin-carrier alif folds to a plain alif instead of being deleted:
  `"شكراً"` -> `"شكرا"` (was `"شكر"`). Number words still drop it
  (`"أربعاً"` -> `4`). Both codepoint orders handled.
- A و/and at the edge of a number span is kept (`"ثلاثة و احنا"` was
  `"3 احنا"`), connector-only spans are left alone (`"و و"` was `"0"`),
  `"واحد"` is no longer split into `"و احد"`.
- Diacritics/tatweel are stripped before matching, so vowelled numbers
  convert whole (`"ألفٍ وسبعمائة وثلاثة وتسعين"` -> `1793`, was `"1000 793"`).
- Separate numbers are no longer merged: `"2020 3"` (was `"20203"`),
  `"2019,2020"` (was `"20192020"`).
- NFD-decomposed input converts the same as composed input.

`normalize_text`
- A `.` between digits survives when `.` isn't enabled punctuation
  (`"2.75"` was `"2 75"`).
- Arabic presentation forms (`ﻻ`, `ﷲ`, contextual shapes) are
  NFKC-decomposed instead of deleted; Persian look-alike letters
  (`ی ک ە ھ ہ ۃ`) fold to their Arabic twins instead of being stripped
  mid-word (`"کتاب یوم"` was `"تاب وم"`).

Tests: new `tests/test_number_roundtrip.py` (generated spoken-number
round-trip search) plus a test per fix in `test_normalization.py`,
47 tests passing. `example.py`/`example.md` gain compound, dialect,
context-rule, tanwin and decimal examples.
